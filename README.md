# Dimensional Collapse and Representation Entanglement

Code for the paper: *"Dimensional Collapse and Representation Entanglement: Context-Dependent Effects of Residual Connections in Over-Parameterized MLP Autoencoders."*

## Overview

We train small and large MLP autoencoders, with and without residual connections, on dSprites and 3D Shapes, and evaluate disentanglement using MIG, DCI-D, DCI-C, and Effective Rank.
